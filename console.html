Versions et accès

Chaque publication garde la version précédente : vous pouvez revenir en arrière à tout moment.

Ce livret n'est pas encore en ligne. « Publier » le met dans la base : vous choisirez alors son adresse définitive (celle du QR code).

Versions précédentes

« Reprendre » charge l'ancienne version dans la console, sans rien changer en ligne. Vérifiez-la, puis cliquez sur « Publier ».

Accès de l'hôte

Créez d'abord le compte de l'hôte dans Supabase (Authentication → Users → Add user, « Auto Confirm User » coché), puis donnez-lui l'accès ici.

    Mise en ligne

    Désactivé, le QR code affiche « Livret introuvable » (fin d'abonnement par exemple). Rien n'est supprimé : réactivez quand vous voulez.

    Formule Premium

    Réservé à la formule Premium. Seul l'administrateur voit ce réglage ; il s'applique à la prochaine publication.

    Exporter

    À coller dans le fichier data/livrets.js du site pour publier le livret pour tous. La version anglaise est incluse.

    Copie de sauvegarde du livret tel qu'il est dans la console (texte à garder de côté ou à réimporter).

    Photos des sorties

    Cherche une photo pour chaque sortie : d'abord la vôtre dans la base (photos/_lieux), sinon Wikimedia. Les photos déposées par le client ne sont pas touchées.

    Importer

    Choisissez le fichier .json du livret, ou collez son contenu. Les photos du client se placent toutes seules.

    Supprime vos modifications sur cet appareil et recharge la version d'origine.
